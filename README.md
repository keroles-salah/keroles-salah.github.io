# Keroles Salah Fakhry - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, experience, projects, certifications, and educational content as a Computer Science student, problem-solving mentor, and tech educator.

## Live Demo

Visit the website:

https://keroles-sala.me

## About The Project

This portfolio presents my personal brand as a Computer Science student and developer.

It includes my background, education, experience, technical skills, featured projects, certifications, and contact links.

The website is designed with a modern dark theme, smooth animations, responsive layout, and interactive visual effects.

## Main Sections

- Home / Hero Section
- About Me
- Education & Certifications
- Work Experience
- Featured Projects
- Technical Skills
- Contact Section

## Features

- Fully responsive design
- Modern dark UI
- Smooth scrolling navigation
- Animated sections using AOS
- Particle background effect
- Interactive skill bars
- Social media links
- Custom domain connected with GitHub Pages
- Clean and organized code structure
